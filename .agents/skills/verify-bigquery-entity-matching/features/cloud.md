# Cloud queries

## Sub-features
Register a remote model, create embeddings, search candidates, and classify mappings.
## How to get to it (user POV)
Use the cloud CLI with existing resources and authorized credentials.
## Driving it with CLI
Run `python -m entity_matching cloud --help` for required resource IDs and operation.
## Gotchas
Cloud operations incur charges and require permissions; never run during local verification.
